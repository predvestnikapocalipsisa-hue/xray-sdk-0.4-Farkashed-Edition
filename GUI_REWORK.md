## Проверка без сборки

SDK DEBUG теперь показывает сцену в Render, включая сетку и управление камерой. Если `shaders.xr` отсутствует, загружаются встроенные редакторские blenders wire/selection, а отсутствующие шейдеры используют однотонный debug fallback. Материалы и частицы загружаются при наличии файлов; отсутствие игрового шрифта не мешает сетке и геометрии.

В Render добавлен Anti-aliasing: Off / SSAA 1.5x / SSAA 2x, по умолчанию 1.5x. Размер render target увеличивается в соответствующее число раз по каждой оси и ограничивается возможностями видеокарты; ImGui уменьшает изображение с линейной фильтрацией. Цветовой и depth targets используют одинаковые размеры, координаты камеры учитывают фактический масштаб. SSAA 2x требует примерно в четыре раза больше пикселей, чем Off.

Depth target редакторов создаётся отдельной DX9 surface: его не требуется читать как текстуру. Проверка успешного создания цветовой текстуры выполняется до обращения к ней в учёте памяти. Если один из targets отсутствует, рендер пропускается и создание повторяется на следующем кадре.

## Уплотнение интерфейса и закрытие SDK

Прозрачность, backdrop blur и edge glow редакторов удалены; старые поля конфигурации читаются для совместимости, но больше не включают эффекты. Из менеджера темы убраны соответствующие настройки. Фон окна непрозрачный, а старые увеличенные отступы ограничиваются при загрузке конфигурации.

Обычные ImGui-кнопки используют стиль control bar: фон интерфейса, плавный hover и акцентный контур. К подписям добавлены встроенные SVG paths; при недостаточной заданной ширине сохраняется читаемая подпись без иконки. Названия плавающих окон и dock-вкладок получили иконки по назначению (Render, Properties, Log, Scene, Library). Место под них учитывается при расчёте ширины и обрезке текста. Чекбоксы имеют компактную высоту; кнопки главного окна занимают 28×28 вместо 40×34, hover проверяется по фактическому положению мыши.

Плавающие окна и popup/combo/menu плавно появляются за 160 мс; стрелки раскрываемых секций плавно поворачиваются. Анимация не меняет координаты и области взаимодействия.

Падение при закрытии в SDK DEBUG происходило в очистке XML-таблиц профилей: инициализация пропущена, но DeleteIdToIndexData разыменовывала пустую таблицу. Добавлена проверка отсутствующей таблицы перед обходом; повторная очистка также безопасна. Файл для merge: `xrServerEntities/xml_str_id_loader.h`. Изменения общего UI: `Editors/XrEUI/{ModernUI.h,imgui.cpp,imgui_widgets.cpp,XrUIManager.cpp}`, `Editors/LevelEditor/color_editor.h`, `XrRender/Private/HW.cpp`.

Выполнены проверки структуры проектов/ресурсов, SVG paths, размеров заголовков/вкладок, затухания hover и защитного условия очистки. Сборка SDK и проверка запуска не выполнялись по требованию пользователя.

Исправлены проверки DX9: формат адаптера отделён от альфа-формата back buffer при выборе depth и render target. Swap effect редакторов соответствует лаунчеру; если создание альфа-буфера не удалось, пробуется формат рабочего стола, а окончательная ошибка создания устройства больше не приводит к обращению к пустому `pDevice` в SDK DEBUG. Все четыре редактора используют `Launcher/assets/gui/Icon.ico` как ресурс MAINICON в своих DLL; RC include path указывает на общий каталог gui. Иконка встроена в DLL и не требует наличия исходного ICO рядом с готовым SDK. В оконном классе назначены большая и маленькая иконки. Для merge включите четыре редакторских `.rc` и `.vcxproj`.

Tools расположен в компактной таблице из двух колонок: Scene Object—Way слева, Sector—Scene fog volumes справа. Поиск балансирует найденные инструменты между колонками; переключатели видимости и выбора сохранены. Длинные подписи ограничены ячейкой и полностью видны в tooltip.

## Анимации открытия и закрытия

Подсказки, popup/menu/combo, плавающие окна и их дочерние списки теперь используют общий цикл появления (160 мс) и закрытия (120 мс). Плавность рассчитывается по DeltaTime с smoothstep. Повторное открытие во время закрытия продолжает анимацию от текущей прозрачности. Оформление Customization остаётся прежним, но анимации применяются и к нему.

После логического закрытия на короткое время отображаются только сохранённые команды рисования; они не регистрируют области ввода и не вызывают действия закрытого UI. Пользовательские draw callbacks не воспроизводятся. Снимки удерживают ссылки на DX9-текстуры и освобождаются после затухания, а также перед reset/shutdown. Дочерние окна затухают вместе с родителем. Dock-панели сохраняют обычную отрисовку без снимков рендера сцены.

Проверены сценарии открытия, закрытия и изменения направления при 30/60/144 FPS, выбор popup/tooltip/child, очистка снимков и структура проектов. SDK не собирался и не запускался.


## DPI Scale

В Customization → Geometry добавлен DPI Scale (75–200%) и Reset DPI to 100%. Изменение применяется перед следующим NewFrame: шрифт, размеры ImGui, toolbar SVG, высота title/control bars и native hit testing используют один масштаб. Размер рендера сцены продолжает определяться размером canvas/SSAA. Снимки анимаций очищаются при изменении DPI, чтобы не показывать старую геометрию.

Save Settings записывает масштаб в ui_settings.cfg v5; v3/v4 читаются с 100%, Reset to Defaults также сбрасывает DPI к 100%. Повторное изменение масштаба не использует округление ScaleAllSizes вниз, поэтому отступы не уменьшаются при перетаскивании ползунка туда-обратно. Применение темы не сбрасывает выбранный DPI.

Проверены многократные изменения масштаба, миграция конфигов, применение до NewFrame и согласованность toolbar/title размеров. Сборка и запуск SDK не выполнялись.
