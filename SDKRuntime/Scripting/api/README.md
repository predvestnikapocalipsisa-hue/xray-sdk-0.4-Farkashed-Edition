# API интерпретатора и редакторов

**[Полный справочник на русском языке — API_RU.md](API_RU.md)**

Подробное описание API 1: создание `.xpy`-аддонов, операторы, панели,
виджеты, сцена и объекты, Undo/Redo, события, таймеры, настройки,
мосты Python ↔ C++/Lua, диагностика, практические рецепты и полный пример.

## Файлы контракта

В этой папке находится публичный контракт системы `.xpy`-аддонов SDK.

- [API_RU.md](API_RU.md) — полный русскоязычный справочник с оглавлением,
  точными сигнатурами, ограничениями, рецептами и законченным аддоном.
- [xray.pyi](xray.pyi) — объявления классов и функций для IDE.
- [SDKScriptABI.h](SDKScriptABI.h) — контракт экспортируемой C-функции.
- [bridge.md](bridge.md) — краткая спецификация UTF-8/JSON-протокола.
- [lua.md](lua.md) — краткое описание преобразования типов Python → LuaJIT.

В установленном SDK примеры находятся в `<sdk_root>/addons`, а реализация
Python-пакета — в `bins/scripting/xray`. Для разрешения `import xray` и
автодополнения укажите IDE путь `<sdk_root>/bins/scripting`: рядом с реализацией
установлен `xray/__init__.pyi`. Расширение `.xpy` свяжите с языком Python.

Текущая версия API — 1. Несовместимая версия в манифесте отклоняется до
выполнения исходника. `.xpy` содержит обычный Python: расширение влияет на
загрузку пользовательских модулей, но не меняет семантику языка. Вызовы C++
и Lua выполняются через мост; исходник не переводится в эти языки.
